# Playbook INTEIRO

Macro sugerido (web app Devin): `!inteiro`

Use quando a sessão implementar UI, CSS, componentes, tokens ou marca.

1. Instalar/consultar `@inteiro/design-system`.
2. Preferir tokens semânticos.
3. Violeta = escolher. Laranja = tornar real.
4. Não aplicar Costura em todo card.
5. Microcopy direto, sem “Oops”.
6. Validar com `npx inteiro audit`.

Playbooks da Devin vivem na web app; este arquivo é a fonte versionada para colar em Settings → Playbooks.

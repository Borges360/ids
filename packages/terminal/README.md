# @inteiro/terminal 1.3.1

Contrato INTEIRO Terminal 1.0.0: componentes como projeções em células, estado, ações e modelos independentes de renderer. Entradas optativas `/pi`, `/prompts` e `/linear` isolam host e IO.

Consulte `docs/terminal/README.md`, `docs/terminal/components.md` e os pilotos `examples/terminal/`. O estado de qualificação é publicado em `docs/terminal/qualification.json`; implementação não equivale a ensaio com leitor de tela.

Núcleo: Node 22.14+. Pi opcional: pi-tui 1.5.2 / Node 22.19+. Inquirer opcional: prompts 7.10.1. Nenhuma dependência opcional é importada pela raiz. Não se presume publicação no registro npm.

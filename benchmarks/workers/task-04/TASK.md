# App shell responsivo

Em mobile, Abrir navegação abre a navegação ‘Navegação principal’ e atualiza aria-expanded. Escape fecha, devolve foco ao acionador e atualiza aria-expanded=false. Em desktop a navegação está disponível sem abrir overlay. Navegue por Início e Pessoas por links acessíveis; não provoque overflow.

Use o contrato INTEIRO em /**inteiro**/composition.css e, se necessário, /**inteiro**/behavior.js. Preserve nomes acessíveis e os data-testid fornecidos. Suporte teclado, target 44px e as quatro variações de tema. Os dados são sintéticos; o avaliador intercepta somente as rotas de API declaradas no fixture.

Implemente apenas os arquivos de src. Não altere política, testes ou baselines. O starter é intencionalmente incompleto e não é uma solução de referência.

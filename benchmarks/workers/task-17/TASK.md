# Perfil com fallback

Carregue GET /api/profile. Exiba nome e e-mail retornados e use iniciais do nome no elemento data-testid avatar quando avatarUrl estiver ausente. Não solicite imagem inexistente. Recarregar perfil consulta novamente, atualiza nome/e-mail e recalcula iniciais, sem preservar dados anteriores.

Use o contrato INTEIRO em /__inteiro__/composition.css. Preserve os nomes acessíveis e data-testid publicados. Suporte teclado, target 44px, reduced motion, RTL e as quatro variações de tema. Implemente somente os arquivos de src, sem alterar controles, testes ou baselines. Os dados de fixtures são sintéticos.

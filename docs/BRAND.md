# Marca

INTEIRO não é cyberpunk, neon, glassmorphism, purple gradient, terminal fake, dashboard enterprise genérico, brutalismo performático, minimalismo vazio nem “AI startup”.

É estrutura + tensão + silêncio + precisão + humanidade + decisão.

A estrutura pesa mais que a expressão. A interface deve ficar mais interessante com o tempo, não mais impressionante em cinco segundos.

Assinaturas:

1. Visual — Costura (`border-inline-start` 2px)
2. Tipográfica — Recursive (MONO + CASL)
3. Comportamental — violeta → laranja
4. Densidade — calm ↔ focus
5. Atmosfera — warm neutral sobre dark (Obsidian / Warm Frost)

Checklist antes de release: a tela parece template SaaS? Purple decorativo? Orange é decisão real? Costura comunica? Há dois primaries? Dark usa preto puro? Funciona em light, teclado, reduced motion e RTL?
